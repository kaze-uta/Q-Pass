# qr_commu — QRコードによるオフラインファイル転送

ネットワークを使わずに、**画面に表示したQRコードを別端末のWebカメラで読み取る**ことでファイルを転送するツールです。送信側がファイルを分割して連続QRコードとして表示し、受信側がカメラで順に読み取って元のファイルを復元します。

物理的にネットワークが分離された環境（エアギャップ）など、通信経路を使わずに少量のデータを渡したい場面を想定しています。

---

## 仕組み

```
[送信側 PC]                         [受信側 PC]
 ファイル                            Webカメラ
   │ 分割(2800バイト/枚)               │ pyzbar でデコード
   ▼                                  ▼
 QRコードを順番に画面表示  ──カメラ──▶  順番に読み取り
   1枚目: 拡張子                       1枚目: 拡張子を取得
   2枚目以降: データ本体                データを追記
   最後: "last" マーカー               "last" で終了 → get.<拡張子> を出力
```

- **1枚目のQRコード**: 送信ファイルの拡張子（例: `txt`, `png`）
- **2枚目以降**: ファイルデータを 2800 バイトずつに分割したチャンク
- **最後のQRコード**: 転送終了を示す `last` マーカー

受信側は読み取ったデータを `get.<拡張子>` というファイルに追記しながら復元します。

## 必要環境

- Python 3.x
- 送信側端末（画面表示用）と受信側端末（Webカメラ付き）

### 依存ライブラリ

| 用途 | パッケージ |
| --- | --- |
| QRコード生成 | `qrcode` |
| 画像処理 | `Pillow` |
| 画面表示・カメラ入力 | `opencv-python` |
| QRコードデコード | `pyzbar` |
| 配列処理 | `numpy` |

インストール:

```bash
pip install -r requirements.txt
```

> **注意**: `pyzbar` は内部で ZBar ライブラリを使用します。
> - Windows: `pip install pyzbar`

## 使い方

2台の端末を向かい合わせ、送信側の画面が受信側のカメラに映るように配置します。

### 1. 受信側を起動（先に待機させる）

```bash
cd receive
python function.py
```

Webカメラが起動し、QRコードの読み取り待機状態になります。

### 2. 送信側でファイルを表示

```bash
cd sent
python main.py <転送したいファイルパス>
```

例:

```bash
python main.py test.txt
```

QRコードが 2 秒ごとに切り替わりながら順番に表示されます。受信側のカメラがそれを順次読み取り、すべて読み終えると受信側ディレクトリに `get.<拡張子>` が生成されます。

### 終了

- 受信側はウィンドウ選択中に `q` キーで終了できます。
- 送信側はすべてのQRコードを表示し終えると自動的に終了します。

## 設定

`sent/main.py` の定数で1枚あたりのデータ量や表示速度を調整できます。

| 項目 | 場所 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `CAPACITY` | `sent/main.py` | `2800` | QR1枚に詰めるバイト数。大きいほど枚数は減るがQRが複雑になり読み取りにくくなる |
| `cv2.waitKey(2000)` | `sent/main.py` `show_qr()` | `2000`(ms) | 1枚あたりの表示時間。受信側の読み取りが追いつかない場合は長くする |

---

## 制限事項・注意点

- 転送は**一方向**（送信側 → 受信側）です。
- カメラの解像度・照明・画面との距離によって読み取り精度が左右されます。読み取りに失敗する場合は `CAPACITY` を下げる、または表示時間を延ばしてください。
- 大きなファイルはQRコードの枚数が増え、転送に時間がかかります。少量データの受け渡しに向いています。
- 同期はQRの差し替え速度（タイマー）に依存する簡易方式のため、確実性が必要な用途には適しません。
